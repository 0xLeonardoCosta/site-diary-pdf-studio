# Site Diary Pdf Studio

eu tenho uma planilha que faço o preenchimento de dados de RDO, gostaria de um modelo de Relatório diário de obras que seja intuitivo e fácil de preencher e coletar informações. Gostaria de uma interface pra preenchimento de informações e um botão pra exportar em pdf de forma que seja visualmente agradável e remetendo as boas execuções de obras.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://site-diary-pdf-studio.lovable.app
